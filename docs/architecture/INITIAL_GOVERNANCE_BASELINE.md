# Initial Governance Baseline

## Baseline

The repository baseline commit is `f7f3f8d`.

The baseline date is September 15, 2026.

This commit starts the public repository after the privacy cleanup.

The commit has no parent commit in this repository.

## Scope

The baseline includes the existing custom App source, governance files, documentation, and approved operational scripts.

The baseline excludes private employee data, payroll history, local credentials, and one-time debug assets.

## Enforcement

Every later pull request must run the existing governance workflows.

The workflows must evaluate the diff from the approved target branch.

This document does not approve new APIs, components, hooks, migrations, dependencies, cross-domain changes, or governance exceptions.

Use the existing registry and approval workflow for each protected change.

Do not replace this baseline with a later commit to approve an implementation.
