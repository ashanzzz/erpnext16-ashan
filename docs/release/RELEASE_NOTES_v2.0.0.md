## 概述 (Executive Summary)

Ashan Enterprise Core `v2.0.0` 是项目自 `v1.9.0-milestone-pre-v2.0` 以来的重大架构演进里程碑。本版本在全面巩固两家公司（祺富与吉众）物理隔离与法定个税/用工成本四柱守恒的基础上，完成了**采购协同履约全链路工作台**的工业级重构，实现了**祺富人事薪酬 4 大前置报表统一核定状态机与住房公积金动态名册导出**，落地了**计薪模式四大标准与临时工前后端动态防御体系**，并全量贯彻了**面向低配硬件的 AshanKit 2.0 零能耗高密度设计规范**。

## 核心更新与业务特性 (Key Features & Enhancements)

### 1. 采购协同履约全链路工作台 (Procurement Fulfillment Suite)
- **五阶单据协同闭环**：
  - 采购申请（SQ）-> 采购订单（CG）-> 采购收货入库（RK）-> 供应商发票勾稽（FP）-> 付款申请（FK）。
  - 支持从前置单据原位一键生成下游单据，自动携带物料、供应商、默认仓库与未结清数量。
- **原位办单与双向穿透足迹 (In-Place Action & Breadcrumb Traceability)**：
  - 看账即办单：在台账与明细穿透的任何位置均可直接发起录单，无需跳转原生表单。
  - 默认提交即生效：高频日常业务默认直接生成已过账（Submitted, `docstatus = 1`）正式单据。
  - 保持单据足迹与面包屑导航，支持正向穿透与平滑回退，杜绝白屏与页面全量刷新。
- **ERPNext 官方生命周期守正 (Lifecycle Audit Guard)**：
  - 严禁物理硬删除任何业务单据，全系统严格执行官方作废与变更生命周期（Cancel & Amend）。
  - 所有单据操作均具备时间戳、操作人与审计追踪（Audit Trail）。
- **采购价格与赠品治理**：
  - 完整支持赠品免验与零元采购订单。
  - 采购入库反哺回填 PO 价格机制，物化待采状态缓存（Materialized Pending Cache）防止数据倒灌。
- **8 阶段标准化复合表头认知流**：
  - 列头布局标准化：标识列 -> 业务主体 -> 物料规格明细 -> 金额与数量 -> 业务流向 -> 经办人员 -> 状态指示 -> 操作通道。

### 2. 祺富人事薪酬 4 大前置报表统一状态机 (Qifu Payroll Sub-report State Machine)
- **四报表统一核定状态流转**：
  - 员工档案底册、车间实发表、社会保险申报表、住房公积金凭证统一接入状态机：`草稿` -> `核验通过` -> `已核定锁定` -> `撤销申请` -> `解锁重核`。
  - 统一顶部状态指示灯与统计：核定账期、社保账期、各前置就绪指示灯。
- **铁的财务前置强拦截**：
  - 四大前置报表未全部确认锁定时，最终工资核定、个人所得税核算与企业综合用工成本台账处于强阻断状态，严禁跨步封账。
- **住房公积金动态名册导出与双模视图**：
  - 深度实现标准公积金汇缴名册格式（原因代码 4），支持【动态汇算表】与【法定名册表】一键平滑视图切换。
  - 自动核验税局社保与公积金凭证金额，不符时实时显式告警。

### 3. 计薪模式全局统一与临时工动态防御体系 (Standardized Salary Modes & Dynamic Guards)
- **四大标准计薪模式**：
  - `税前动态工资`：按工时/考勤动态计算税前应发，扣除社保公积金后计算个税与实发。
  - `税后动态工资`：车间实发表以实发为基准，闭式 7 级预扣反推税前应发与个税。
  - `税前固定工资`：固定约定税前薪资，减除各项扣除后计税发薪。
  - `税后固定工资`：管理岗税后净额包干，1:1 VBA 闭式精确反推税前应发与代扣个税。
  - `不税动态工资`：车间纯临时工/临时兼职专属模式，不扣社保公积金与个税。
- **临时工业务强联动防呆**：
  - `employee_type == '临时工'`：计薪方式强制锁定为 `不税动态工资`，前端置灰只读，后端强校验自动归一。
  - `employee_type != '临时工'`：计薪方式下拉列表严格剔除 `不税动态工资`，仅允许四选一；后端如检测到非临时工传入不税模式直接阻断抛错。
- **存量历史数据清洗与迁移**：
  - 祺富与吉众两家公司历史存量档案 100% 迁移至标准模式，0 违规、0 脏数据。
- **权限与环境连通性彻底解决**：
  - 移除了限制管理员账户 `ashanzzz1213@gmail.com` 的 `tabUser Permission` 历史记录，彻底恢复全局双主体读写与管理权限。

### 4. AshanKit 2.0 工业级设计语言与低功耗高性能渲染基准
- **3 代 Intel 低配硬件基准 (Ivy Bridge HD 2500/4000)**：
  - 全局严格禁止 `backdrop-filter: blur` 磨砂玻璃滤镜，统一采用实色浅边框与低开销纯色遮罩。
  - 全局严格禁止大半径重阴影与非必要过度逐帧动画，消除 CPU 逐帧重绘负担。
- **全局 24 个自定义模块样式收敛**：
  - 彻底淘汰黑色大实体按钮、彩色卡片边框与冗长口号副标题。
  - 严格执行零装饰性 Emoji 铁律，仅保留必要的状态指示灯。
  - 单层复合表头与鼠标滑轮横向滚动（Mousewheel-to-Horizontal Scroll）体验无缝统合。

## 破坏性变更与兼容性说明 (Breaking Changes & Migration)

1. **计薪方式 Select 选项收敛**：
   - 历史选项 `税后`、`税前`、`税后管理工资` 已正式废止并从 DocType Select 选项中剔除。
   - 依赖旧字段值的外部脚本或直接 SQL 查询必须更新为使用上述四大标准模式或 `不税动态工资`。
2. **非临时工选择限制**：
   - 非临时工人员（正式工、返聘工等）无法再设置为 `不税动态工资`，否则将在保存时触发 `ValidationError`。
3. **单据删除接口废除**：
   - 自定义工作台已彻底禁用单据物理删除功能，统一走 ERPNext 官方 `cancel` 流程。
