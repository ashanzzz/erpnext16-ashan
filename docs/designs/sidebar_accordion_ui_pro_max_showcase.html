大标题聚合纯数字待办 (Rollup Bubble-up)

大标题待办数字为子项待办的实时数学求和（如采购执行 4 + 收货入库 6 = 10）。手风琴折叠时常驻于标题与右侧箭头之间，彻底消灭折叠导致的信息黑洞。

纯数字无“笔”字严肃规范 (Pure Number Standard)

胶囊内严格只保留纯等宽数字（tabular-nums），尺寸高度锁定 18px，消除汉字对水平视线的挤压干扰，数字在 1 位、2 位或 99+ 变动时绝对平稳无跳动。

16px 物理阶梯缩进 (Physical Stepped Indent)

二级子菜单采用 padding-left: 16px 自然阶梯对齐，彻底移除了原生粗糙的 1px 实线框，让大宽表与侧栏视线扫描平滑畅通。

前置 4px 品牌蓝光圆点 (Blue Pulse Dot)

当前激活工作台前置 4px 钴蓝圆点，外带 0 0 6px rgba(37,99,235,0.5) 呼吸光晕，配合 #eff6ff 柔和微蓝底色，视线瞬间锁定当前工序。

零像素布局重排抖动 (Zero Layout Shift)

全部条目预置 1px solid transparent 边框，鼠标悬浮时仅渐变底色与边框色，彻底杜绝导致肉眼疲劳的 1px 抖动与任何 translateY 亚像素模糊。
