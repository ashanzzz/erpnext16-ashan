# Excel 导出与打印工程规范

目标：导出的工作簿既能供电脑复核，也能在黑白打印、财务归档、独立签收场景下保持严肃、清晰、可计算。

## 1. 黑白财务底册

- 默认纯白底、黑字 `#000000`，不使用黄绿紫蓝等糖果色背景。Web 的状态色不直接搬到纸质 Excel。
- 表格外框、表头上下边、最左定位列、最右核定列及业务/辅助列分界使用 Medium 黑色边框；内部网格使用 Thin 黑色边框；合计行底边使用双线或加粗边框。
- 字号与行高保持紧凑：企业发薪标题可为合并单元格、约 15pt 加粗、40–42 高；标准列头约 11pt、26 高；数据行约 10pt、22 高；合计行约 10.5pt 加粗、24 高。除非用户指定，不插入冗余“生成日期/人数/发薪月份”统计副标题。

## 2. 自适应与纸张边界

- 所有表头与数据单元格设置 `shrink_to_fit = True`，防止长姓名、大金额产生 `###` 或截断。
- 打印设置横向 A4，开启 `fitToWidth = 1` 与 `fitToPage = True`，保证一页宽而不横向拆页。
- 每页重复标题行按模板配置。工资签收类表通常为第 1–2 行；不是所有 Excel 均机械套用该范围。
- `print_area` 只包含允许打印的业务列，不把电脑复核辅助列、点钞列或技术列带上纸面。

## 3. 车间外部实发表模板

当导出的是已经确认的“车间外部实发表”模板时：

- 物理打印业务区为 24 列，即 `A:X`；第 25–31 列仅用于电子版点钞/找零辅助，不进入打印区域。
- 纸质签收要求一人一页时，在每位员工数据行后添加硬分页符；同一工作簿内的总表/管理汇总不应无差别添加分页。
- 模板列数、打印列、辅助列由导出配置表达。若用户日后变更模板，不把 `A:X` 当成任何其他报表的硬编码默认值。

## 4. 活公式优先

- 可由 Excel 计算的值必须写入公式而非导出的死数值：小计 `SUM`、补贴/扣减加减、现金面额乘积、找零校验和四舍五入均保留公式。
- 公式引用和总计范围随数据行数动态生成；不可复用样例中的固定行号。
- 公式、数值格式和总计口径要与服务端核算结果一致；Excel 公式提供二次复核，不得成为绕开服务端财务校验的途径。

## 5. 导出前后的二进制断言

每次变更 Excel 导出，都编写或更新针对生成 `.xlsx` 的 Python 断言，至少检查：

1. 工作表名称、标题、表头、实际数据行和合计行。
2. 关键单元格的 `shrink_to_fit`、字体、填充、对齐和边框粗细。
3. `print_area`、纸张方向、`fitToWidth`、重复标题行和分页符。
4. 公式存在、引用范围正确、金额格式正确；不把公式结果序列化为静态数字。
5. 车间实发表的电子辅助列不出现在打印区域，且单人签收分页仅用于指定导出类型。
